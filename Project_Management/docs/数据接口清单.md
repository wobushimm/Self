# 数据接口配置示例

公开版不包含任何真实平台地址、账号、项目 ID、内部接口路径、数据库名称或表名。

## API 配置

```bash
export PMO_API_BASE_URL="https://api.example.com"
export PMO_API_USERNAME="your_username"
export PMO_API_PASSWORD="your_password"
export QUALITY_API_TOKEN="your_token"
```

`config/data_sources.yaml` 中的路径均为示例。接入自有平台时，请根据实际 API 修改，并避免把真实凭证写入代码或提交到版本库。

## 数据库配置

数据库通道是可选的：

```bash
export PMO_DB_HOST="db.example.internal"
export PMO_DB_PORT="3306"
export PMO_DB_USER="readonly_user"
export PMO_DB_PASSWORD="your_password"
export PMO_DB_DATABASE="project_management"
```

请仅使用只读账号，并通过环境变量或密钥管理服务注入凭证。

## 脱敏说明

- 示例域名使用 `example.com`。
- 示例项目名称、ID 和指标值不对应任何真实项目。
- 组织总人数通过 `COMPANY_HEADCOUNT` 配置。
- 内部请求头、数据库结构和专用接口名称未包含在公开版中。
