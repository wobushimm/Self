# 项目管理快报 Skill 功能介绍

本项目用于从可配置的数据源读取项目数据，计算项目管理指标，并生成 HTML、PDF、Word 和演示文稿格式的快报。

## 主要能力

- 按项目和月份生成报告。
- 计算工时、预算、质量、需求和交付相关指标。
- 对缺失数据进行校验和降级处理。
- 支持 API、可选只读数据库及本地数据源。
- 支持通过兼容 OpenAI 接口的模型生成分析文字。

## 公开版配置

公开版不带真实接口、凭证、项目编号、组织人数或内部数据库结构。运行前至少配置：

```bash
export PMO_API_BASE_URL="https://api.example.com"
export PMO_API_USERNAME="your_username"
export PMO_API_PASSWORD="your_password"
export COMPANY_HEADCOUNT="100"
```

模型功能可通过 `VLLM_BASE_URL`、`VLLM_MODEL` 和 `VLLM_API_KEY` 配置。数据库通道所需变量见《数据接口清单》。

## 安全要求

- 不要提交 `.env`、Cookie、Token、密码或生产数据快照。
- 示例输出不得包含真实员工、客户、项目或财务数据。
- 发布前运行仓库敏感信息扫描，并检查 Git 历史。
