# 其他费用预算管理（本地全栈版）

本版本保留 `其他费用预算MVP` 静态原型，同时新增一次性运行的本地桌面程序。

## 功能

- 先上传财务规则模板，再读取部门线下发送的 `.xlsx` 其他费用预算明细；
- 按规则模板第一行字段校验部门文件是否缺列；
- 校验必填字段、金额、同比增长阈值、零基数新增费用与重复提交；
- 数据仅在当前程序运行期间保存在内存中，关闭程序后自动清空；
- 证明附件仅用于本次导入核验，不会复制或保存；
- 财务人员在“财务审核”页通过或退回记录；
- 导出两个 Sheet：`预算审核明细` 展示全部当次记录（含已退回），`按部门汇总` 分列已通过、已退回和待审核金额。

## 启动

双击 `启动其他费用预算管理.command`，或执行：

```bash
zsh 启动其他费用预算管理.command
```

## 使用顺序

1. 选择财务维护的规则模板；第一行表头即为部门文件必须具备的字段。
2. 选择部门线下发送的预算 Excel，以及可选的测算依据、报价单或合同附件。
3. 点击“导入并校验”；缺少规则模板字段会按异常数据阻断，并给出补齐提示。
4. 点击“提交财务审核”。
5. 财务在“财务审核”页选择一条待审核记录后通过或退回。
6. 在“汇总导出”页输出审核明细和按部门汇总。

## 一次性运行边界

- 不创建 SQLite 数据库，不保存附件、预算、审核记录或历史版本；关闭窗口后所有当次数据清空。
- 当前审核意见是固定的默认文案；集成到公司 UI 后可由外壳提供账号、权限和审批流。
- 当前 Excel 金额单位固定为“万元”，同比阈值预置：差旅 20%、推广 30%、咨询 30%、办公 15%，其他项目默认 20%。
