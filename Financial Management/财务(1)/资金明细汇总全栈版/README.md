# 资金明细汇总工具（本地全栈版）

这是一个聚焦“部门小表合并 + 按日报栏目汇总”的本地桌面工具，界面形态与资金日报、其他费用预算工具一致，不需要浏览器。

## 启动

双击 `启动资金明细汇总.command`，或在此目录执行：

```bash
python3 python/资金明细汇总管理界面.py
```

无需安装第三方依赖；数据只保存在本次程序运行的内存中，关闭程序后自动清空。工具不会创建数据库，也不会保存导入的小表或明细记录。

## 使用

1. 右侧默认展示已合并的测试明细数据。
2. 左侧可手工新增一笔记录，提交后立即汇入明细大表。
3. 也可直接导入 `.xlsx` 格式的部门小表；第一张工作表应包含“部门、预计日期、日报栏目、收支方向、金额”，事项说明可选。
4. 点击“按日报栏目汇总”，查看各栏目收入、支出、净额及笔数。
5. 点击“导出汇总大表 Excel”，输出包含“资金明细大表”和“日报栏目汇总”两个 Sheet 的正式文件。

## 预置日报栏目

销售收款、采购付款、费用支出、工资、奖金、内部往来、社保及公积金、税金、其他收入、其他支出、投标保证金。

其中“内部往来”可按实际情况选择收入或支出，其余栏目的收支方向也允许在导入或手工新增时明确填写。

## 当前边界

当前支持 `.xlsx` 单工作表导入和两 Sheet 的 Excel 导出；后续可按最终财务 Excel 模板增加多 Sheet 导入、公式输出、日期/公司筛选和权限登录。
