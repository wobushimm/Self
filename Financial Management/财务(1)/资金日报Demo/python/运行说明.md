# 资金日报本地 Demo：使用说明

请将以下内容一起发送或压缩：

- `python` 文件夹（本文件所在文件夹）
- `资金日报Demo输入n_规则配置版.xlsx`（模板与规则文件）
- 一份当天从司库导出的交易明细 Excel 文件

## 第一次运行前

安装 Python 3 后，在 VS Code 终端进入本文件夹，执行：

```bash
python3 -m pip install -r requirements.txt
```

## 运行

在 VS Code 打开 `资金日报上传生成界面.py`，在终端执行：

```bash
python3 资金日报上传生成界面.py
```

Mac 用户也可以双击 `启动资金日报上传界面.command`。

Windows 用户建议直接双击 `启动收付明细自动生成.bat`。若首次提示缺少依赖，在本文件夹的终端执行一次：

```bash
py -3 -m pip install -r requirements.txt
```

## 界面中选择的文件

- 当天司库文件：当天导出的文件，只需要含 `司库交易明细` Sheet。
- 模板与规则文件：长期维护的 `资金日报Demo输入n_规则配置版.xlsx`；其中必须有 `日报模板`（或 `收付明细`）和 `特殊摘要规则` Sheet。
- 输出收付明细：选择新文件的保存位置。

规则只修改“模板与规则文件”的 `特殊摘要规则` Sheet；不要在生成结果文件里维护规则。
