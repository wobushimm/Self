# 资金日报自动生成 Demo

本 Demo 按财务确认的真实表结构工作：从司库交易明细填充日报模板。它在本地离线运行，后续公司 UI 壳可复用同一套 Python 核心逻辑。

## 最简单的使用方式

双击：`python/启动资金日报上传界面.command`

在窗口中：

1. 选择当天司库文件；
2. 选择长期保存的“模板与规则”文件；
3. 付款摘要未带“采购/费用/内部往来”标注时，点击“同步特殊规则”，再在“模板与规则”文件的 `特殊摘要规则` Sheet 填写 F 列“编码(H)”和 G 列“收付项目(I)”并保存；
4. 回到窗口，填写真实期初余额，点击“生成资金日报”。

## 已实现的固定列映射

- 司库 E（银行账号）→ 日报 F（银行账号）
- 司库 J（对方户名）→ 日报 G（往来单位）
- 司库 N（付款金额）→ 日报 K（支出）
- 司库 O（收款金额）→ 日报 J（收入）
- 司库 H（交易日期）→ 日报 B（日期）及 A（年-月）
- 日报 C/D/E/L：沿用日报模板的公式。

收款只要金额来自司库“收款金额”列，即直接填为 `1、销售收款`。付款的 H（编码）和 I（收付项目）优先由摘要中的人工标注决定：采购→2、采购付款；费用→3、费用支出；内部往来→5、内部往来。未带标注的付款才查 `特殊摘要规则`；规则未命中、规则冲突和多标注付款进入 `H_I待配置`。

## 文件说明

- `python/generate_treasury_daily_template.py`：核心日报生成逻辑。
- `python/资金日报上传生成界面.py`：点击上传、选择输出与生成日报的本地界面。
- `python/启动资金日报上传界面.command`：双击启动界面。
- `测试表/资金日报Demo输入n_规则配置版.xlsx`：带 `特殊摘要规则` Sheet 的财务配置示例。

## 终端调用

```bash
python python/generate_treasury_daily_template.py \
  --input "资金日报Demo输入n_规则配置版.xlsx" \
  --output "资金日报_2026-08-03.xlsx" \
  --opening-balance "10000.00"
```

`--opening-balance` 是日报首笔交易发生前的真实期初余额，必须由财务提供。
