# Financial Management

这是从原始财务目录生成的脱敏副本。公开版只保留程序代码、使用说明和明确标记的虚构示例，不包含原始交易明细、资金日报、部门预算数据、截图或生成结果。

## 使用前说明

- 运行程序产生的 Excel、CSV、PDF 和 `output/` 内容默认不会进入 Git。
- 请勿把真实银行账户、交易流水、公司名称、客户信息、人员信息或财务金额提交到仓库。
- 其他费用预算模板可由程序的 `create_template()` 函数在本地生成；仓库不附带原始工作簿。
- Demo 数据使用“示例公司”“示例银行”和 `DEMO-*` 标识，不对应真实主体。

## 发布前检查

提交前请再次检查暂存文件，并扫描密钥、账号、身份证号、手机号、本机绝对路径及公司内部名称。
